# Portfolio site

A simple static portfolio for GitHub Pages.

## Before publishing

Replace these placeholders in `index.html`:

- `First Last`
- `first@firstlast.io`
- `YOUR-LINKEDIN`
- `YOUR-GITHUB`
- `Current Company`
- any job titles / dates you want to change

Add your finished resume as `resume.pdf` in the repository root.

## Publish

Commit `index.html`, `styles.css`, and `resume.pdf` to the GitHub Pages repository.
GitHub Pages will serve the site automatically from the configured branch.
